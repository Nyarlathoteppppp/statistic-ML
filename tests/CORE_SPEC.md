# js/core implementation spec (for delegate)

Goal: implement the pure-algorithm modules under `js/core/` so that `node tests/core.test.js` passes. **`tests/core.test.js` is the contract** — read it fully first; every function name, argument order, return field name and value format used there must exist exactly. Do NOT edit the test file.

## Files to create (one per module)
`js/core/vc.js, bandit.js, cnn.js, svm.js, dsep.js, elim.js, cpt.js, perceptron.js, stats.js, bayes.js, experts.js, kernel.js, backprop.js`

## Module pattern (mandatory — the site is opened via file:// so no ES modules, no require inside modules)
```js
(function (root) {
  'use strict';
  const api = { /* functions */ };
  root.SML = root.SML || {};
  root.SML.core = root.SML.core || {};
  root.SML.core.vc = api;                       // module name = file name
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
})(typeof window !== 'undefined' ? window : globalThis);
```
- Plain ES2017, no dependencies, no DOM access, deterministic (any randomness takes a seeded RNG argument).
- Functions return plain JSON-able objects. Prefer returning **step traces** (arrays of intermediate states) because the UI will animate them step by step.
- Short JSDoc on each exported function: params, return shape, and the lecture page it implements (e.g. `// L20 p17`).

## Behaviour notes beyond what the tests pin down
- **vc**: `restrict(rows, subset)` → `{subset, patterns (restricted rows in original order, as strings like "01"), unique (sorted unique strings), needed: 2^k, shattered}`. `analyze(rows)` → `{n, vc, maxSets, allShattered (incl. empty set []), bySize {size: count}}`; enumerate subsets in increasing size. `stumps(xs, ys)` → sort by x, thresholds = midpoints between consecutive sorted distinct xs; `mistakesPos` for sgn(x−β) (+1 if x>β), `mistakesNeg` for sgn(β−x); `best` = minimum over both (ties: prefer smaller mistakes then 'pos' then smaller β); also return `predictionsPos/Neg` tables. `stumpDichotomies(xs)` → unique label vectors over all thresholds incl. below-min and above-max, both orientations (as strings of '+'/'-').
- **bandit**: `ucb(arms, opts)`; arms `{n, s}` (pulls, total reward). opts: `t` (default Σn + 1), `rho` (default 2), `Q0` (default Infinity), `ln` (optional lookup {t: value} used instead of Math.log when present). Return `{t, lnT, arms:[{n, s, mean, bonus, Q}], choice: [indices of all maximisers]}`. `greedyChoice(arms, Q0)` returns argmax indices of empirical mean (Q0 for unpulled). Also export `epsGreedyProbs(arms, eps, Q0)` and a seeded `simulate({means, rounds, policy, eps, Q0, rho, seed, rewardFn})` returning per-round choices/rewards (Bernoulli rewards by default).
- **cnn**: `network(layers, {bias})`: layer types `conv1d {inputs, kernel, stride, shared}`, `dense {out}` (inputs inferred from previous layer outputs). conv1d outputs = floor((inputs−kernel)/stride)+1; shared params = kernel (×1 filter), unshared = outputs×kernel; bias adds 1 (shared) or outputs (unshared) for conv, `out` for dense. Return `{layers:[{type, inputs, outputs, params, formula}], total}` where `formula` is a short human-readable string like "5 × 4 = 20". `conv2d({H,W,Cin,K,Cout,stride,pad})` → `{outH,outW,outC,weights,biases,params,formula}` with out = floor((H+2pad−K)/stride)+1, weights = Cout·Cin·K². `pool2d({H,W,C,K,stride})` → `{outH,outW,outC,params:0}`.
- **svm**: `hardMargin2D(points)` exact for small 2D separable sets: enumerate candidate support sets (pairs of opposite classes → perpendicular bisector; triples with two from one class → line parallel to that pair's direction, equidistant), keep feasible separators (all yᵢ(w·xᵢ+b) ≥ 1−1e-9 after canonical scaling), choose the max margin. Return `{w, b, margin (=1/||w||), supportVectors: ids with yᵢ(w·xᵢ+b)=1 (tol 1e-9)}` with canonical scaling. Throw if not separable. `hinge(y, s) = max(0, 1−y s)`, `distance(w, b, x) = (w·x+b)/||w||`.
- **dsep**: DAG as edge list `[[parent, child], ...]`. Export `ancestors(edges, nodes)`, `moralize(edges)` → `{edges (undirected, includes original), added}`, `separated(undirectedEdges, X, Y, S)` → `{separated, path}` (BFS shortest path avoiding S, path from first X to first reachable Y, else null), and `dsep(edges, X, Y, S)` → `{independent, steps:{ancestral (node list), ancestralEdges, moralEdges (added marriages only), undirectedEdges, removed: S, path}}`. Path tie-break: BFS visiting neighbours in alphabetical order.
- **elim**: `eliminate(edges, order)` → `{steps:[{node, neighbours, fill (new edges), clique (node ∪ neighbours)}], maximalCliques (remove cliques that are subsets of others, keep first-seen order), junctionTree:{nodes: maximalCliques, edges:[{a, b, separator}]}}`; junction tree = maximum-weight spanning tree on separator size (Kruskal, deterministic tie-break by clique index).
- **cpt**: `sizes(parents, card)`; `parents` = `{node: [parents]}`; `card` = `{node: k}` or null (all binary). Each table: `{node, parents, parentConfigs, shape:[card(node), parentConfigs], entries, free: (card−1)·parentConfigs}`; return `{tables, totalEntries, totalFree}`. `joint(card)` → `{entries, free}`. `mle(parents, data, values)` → `{node: {parentKey: {counts:{value:count}, total, p:{value:prob|null}}}}` where parentKey joins parent values in the parents' listed order with ',' ('' for roots); include all parent configurations, with p = null when total = 0.
- **perceptron**: weights `[w0 (bias), w1, ...]`, inputs without the bias 1 (prepend internally). `train(data, w, eta, {epochs, order})` → `{steps:[{i, x, y, s, ys, updated, w (after)}], w}`; update when ys ≤ 0 (L10 p18). `loss(s, y) = max(0, −s y)`.
- **stats**: `mean`, `variance` (population, ÷m — matches L15 p29), `welch(a, b, m)` with `a = {mean, var}`: `x = (μ1−μ2)·√m / √(σ1²+σ2²)`, `nuRaw = (σ1²+σ2²)²(m−1)/(σ1⁴+σ2⁴)`, `nu = ceil(nuRaw)`; `errorBar(mean, var, m, crit)` → `{lo, hi, half = √var/√m · crit}`; `metrics({TP,FP,TN,FN})` → precision, recall (= sensitivity), specificity, accuracy, f1, fpr.
- **bayes**: `betaBinomial(alpha, beta, n, k)` → `{alpha: α+k, beta: β+n−k, mean, map (null if undefined), mle: k/n}`. `linreg(X, y, sigma2, gamma2)` → `{wN, VN}` with `VN = σ²(XᵀX + σ²/γ² I)⁻¹`, `wN = (1/σ²) VN Xᵀ y` (L18; matches the 2021 exam formula sheet); include a small Gaussian-elimination matrix inverse. `predict(post, xStar, sigma2)` → `{mean, var: σ² + x*ᵀ VN x*}`.
- **experts**: `majorityBound(n) = log2 n`; `halvingBound(m, n) = (m + log2 n)/log2(4/3)`; `weightedBound(m, n, eps) = 2(1+eps)m + 2 ln n / eps`; `finiteClassBound(F, delta, n) = sqrt((ln F + ln(1/delta))/(2n))`; `vcBound(vc, delta, n) = sqrt(8 (vc·ln(2n+1) + ln(4/delta)) / n)`. `run(kind, predictions, outcomes, {eps})` with kind ∈ 'majority' | 'halving' | 'weighted'; predictions[t][i] ∈ {0,1}; returns `{learnerPreds, mistakes, expertMistakes, weights (after each round, array of arrays)}`. majority: drop experts that err (weight 0); halving: ×½; weighted: ×(1−eps). Learner predicts weighted majority (ties → 1).
- **kernel**: `dot`, `poly(u, v, c, d) = (u·v + c)^d`, `phi1d(x, c) = [x², √(2c)·x, c]`, `polyFeatures(x, d)` for c = 0 returning the monomial map with multinomial-coefficient square roots (for d=2,m=2: [x1², √2·x1x2, x2²]), `rbf(u, v, gamma)`, `gram(points, k)`, `isPSD(M)` (symmetric eigen check via Jacobi or Cholesky with tolerance).
- **backprop**: `run(net, x, y)`; `net = {V (V[i][j], input i incl. bias row 0 → hidden j), w (w[0] bias weight on u0 = 1, then hidden weights), act: 'logistic'|'tanh'|'relu'}`; identity output, `L = ½(z−y)²`. Return `{r, u, s, z, L, delta, eps (per hidden j), dW (length p+1, dW[0] = δ), dV (dV[i][j] = ε_j x_i)}` following L11 p28–p31 notation.
