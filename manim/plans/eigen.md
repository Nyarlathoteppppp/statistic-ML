# eigen · 特征向量（c04）

## Overview
- **Hook**：矩阵会把整个平面拉扯变形——有没有方向，变换后仍在原来那条直线上？
- **Key insight（aha，第 5 步）**：“不转向的方向”就是 A·v = λ·v；λ 只是那条线上的拉伸倍数。
- **Narrative pattern**：Specific → General + 反例对照（普通向量会转向 → 特殊方向不转向 → 命名 → λ = 0 的反面）。
- **FLOW**：矩阵 = 拉扯平面 → 普通向量会转向 → 特殊方向不转向 → 命名 A·v = λ·v → λ = 0 ⇒ 不可逆
- **Emotional arc**：好奇（提问）→ 困惑（普通向量都转了）→ 部分明白（(1,1) 只拉长）→ aha（命名）→ 满足（λ = 0 解释了 X′X 不可逆）。

## Steps（skeleton = 被拉扯的网格，全程不清空）
1. Purpose：矩阵是什么动作。Visual：网格 + î、ĵ 被 A 拉扯。Math：A 的两列 = î、ĵ 的落点。
2. Purpose：大多数向量会转向（反例）。Visual：黄向量 (1.5, 0.5) 和它所在的虚线，变换后离开虚线。Math：(3.5, 2.5)。
3. Purpose：存在不转向的方向。Visual：青色 (1,1) 及其直线，变换后仍在线上。Math：×3。
4. Purpose：再找一个。Visual：紫色 (1,−1) 不动。Math：×1。
5. Purpose：命名（aha）。Visual：A·v = λ·v，两边各标作用：“变换后的 v”“原来的 v 拉长 λ 倍”。
6. Purpose：λ = 0 的意义。Visual：换成 B，整个平面塌成一条线，紫色向量缩成一点。Math：λ = 0 ⇒ 不可逆。

## Colours
绿 î、红 ĵ（基向量）；黄 = 普通向量；青、紫 = 两个特征方向；网格蓝。

## Takeaway
特征向量：变换后仍在原来直线上的方向 / 特征值 λ：在这条线上被拉伸的倍数 A·v = λ·v / 有 λ = 0 ⇒ 某个方向被压成零 ⇒ 不可逆
