# eigen · 特征向量（c04）

## Overview
- **Hook**：矩阵会把整个平面拉扯变形——有没有向量，变换后仍在原来那条直线上？顺带：矩阵什么时候能“撤销”？（最后一步 λ = 0 回答）
- **Key insight（aha，第 5 步）**：“变换后仍在原直线上的**非零**向量”就是 A·v = λ·v；λ 是它被乘的倍数，可正、可负、可为 0。
- **Narrative pattern**：Specific → General + 反例对照（普通向量离开原线 → 特殊向量仍在原线上 → 命名 → λ = 0 的后果）。
- **FLOW**：矩阵 = 拉扯平面 → 普通向量离开原线 → 特殊向量仍在原直线上 → 命名：A·v = λ·v → λ = 0 ⇒ 不可逆
- **Emotional arc**：好奇（提问）→ 困惑（普通向量都离开了原线）→ 部分明白（(1,1) 只被 ×3）→ aha（命名）→ 满足（λ = 0 解释了“撤不回”和 X′X 不可逆）。

## Conventions（全程一致）
- skeleton = 被拉扯的网格，全程不清空；暗色背景网格 = 变换前，留作对照。
- **回到变换前**：每换一个新向量前，先淡出上一步的结果标签和字幕 → 顶部浅色药丸“回到变换前” → 网格 1.1 s 复原 → 停 0.6 s → 才出新字幕和新向量。
- **淡色宽箭头（ghost）= 变换前的向量**，留在原处；亮色细箭头 = 变换后。虚线 = 向量原来所在的直线（静止不动；唯一例外是第 6 步 λ = 0，紫虚线和紫 ghost 随 B 缩进原点）。
- î、ĵ 在第 2–5 步调暗（透明度 0.3），第 6 步恢复。î 标签在箭头右下、ĵ 在左上，B 把两者送到同一点时不会叠字。

## Steps
1. 矩阵是什么动作。网格 + î、ĵ 被 A = [[2,1],[1,2]] 拉扯。Math：A(1,0) = (2·1+1·0, 1·1+2·0) = (2,1) = 第 1 列，ĵ → 第 2 列 (1,2)。
2. 普通向量离开原线（反例）。回到变换前 → 黄向量 (1.5, 0.5)、黄虚线、淡黄 ghost → 变换后亮黄到 (3.5, 2.5)，标签“A·v = (3.5, 2.5)”，ghost 仍在虚线上。Math：3.5÷1.5 ≈ 2.3 ≠ 2.5÷0.5 = 5。
3. 特殊向量仍在原直线上：×3。回到变换前 → 黄色淡出 → 青色 (1,1)、青虚线、淡青 ghost → 变换后到 (3,3)，仍在虚线上；(1,1)、(2,2) 两道白刻度把它分成相等 3 段（第一段正是 ghost），标签“×3”。
4. 另一个：×1。回到变换前（青色回到 ghost 上）→ 紫色 (1,−1)、紫虚线、淡紫 ghost + 线上 3 个紫点 (−2,2)、(−1,1)、(2,−2) → 变换时网格动，紫箭头和紫点不动；“×3”“×1”同时显示。字幕：“倍数是 1，这条线上每个点都停在原地”（不说“拉伸 1 倍”）。
5. 命名（aha，只做定义）。“×3/×1”就地变成“λ = 3 / λ = 1”。左下公式卡：A v = λ v + “v ≠ 0”；上方名称（细连线指向符号）“特征向量”→ v、“特征值”→ λ；下方作用“变换后的 v”“原来的 v 乘以 λ”（位于画面中部偏下，远离底部字幕）。Flash 两个特征向量的箭头尖。公式卡下方静态小图 3 格（淡 = v，亮 = λv，虚线 = v 的直线）：λ > 0 同向 / λ < 0 反向 / λ = 0 变成零点，淡入后停约 3.6 s。完整公式在屏上 ≥ 4 s。旁白不讲 PD / 可逆，只留一句指向正文 ⑤。
6. λ = 0 ⇒ 不可逆。回到变换前 → 青 ghost 淡出、标签换成 B = [[1,1],[1,1]]、î ĵ 恢复亮度（ĵ 粗红在下、î 细绿在上）→ 网格塌成斜线（2.4 s）：紫箭头和紫点缩进原点；**紫虚线和淡紫 ghost 也随同一个变换缩进原点（ghost 同时淡出）**，变换后两者移除——画面上不再留任何“紫色停在原处”的东西（与第 4 步 λ = 1 区分）；青色到 (2,2)。随后原点出现明显紫点（半径 0.12）+ 紫色 Flash，标签“(1,−1) → 0：λ = 0”贴在紫点右下；“(1,1) → (2,2)：λ = 2”。停 0.8 s 后加**一条**标签“î 和 ĵ 都变成 (1,1)：撤不回”（在 (1,1) 左上方，避开 ĵ 字母）+ Flash，停 2.2 s；î、ĵ 小字母**不淡出**，分列共同箭头尖的右下 / 左上两侧，暂停帧里仍看得出“两个输入 → 同一个输出”。字幕：“λ = 0：紫箭头和紫点被压到原点，î、ĵ 都落到 (1,1) ⇒ 撤不回”。例外：本步紫虚线不再静止（它本身就是被压扁的对象）。

## Colours
绿 î、红 ĵ（基向量）；黄 = 普通向量（第 5 步小图里黄 = 通用 v/λv）；青、紫 = 两个特征向量；网格蓝；“撤不回”黄色强调。

## Takeaway
特征向量：非零向量 v，变换后仍在原来那条直线上 / 特征值 λ：它被乘的倍数 A·v = λ·v（λ 可正、可负、可为 0）/ 有 λ = 0 ⇒ 某个方向被压成零点 ⇒ 撤不回（不可逆）
