# dot · 向量点积与几何投影（c03）

## Overview
- **Hook / Question**：两个向量的点积，为什么既能按坐标相乘相加，又能算投影长度？代数与几何为什么必然给出同一个数字？
- **Key insight（aha，第 2 步）**：点积就是“目标向量的长度 × 影子长度”。无论怎么转，投影的物理缩放与坐标代数计算分秒不差、实时恒等。
- **Narrative pattern**：Two perspectives → Unity（代数分量和与几何投影乘积的统一），由浅入深连接至线性分类器。
- **FLOW**：定义两向量 → 投影与点积 → 360°旋转 → 正交：积为0 → 连接分类器
- **Notation（与 c03 一致）**：点积写 u′v（一撇 = 转置），公式卡第一行注明“也写作 u·v”；长度写 ‖u‖（单竖线 |·| 在 c03 里是绝对值）；字母下标一律 MT('x<sub>A</sub>')，不出现下划线。纯数字相乘用 ×。
- **Persistent skeleton**：左侧等比例坐标网格（x ∈ [-3, 3.8], y ∈ [-2.8, 2.8]）、原点、向量 u 及其所在直线；右侧为公式面板与实时同步双读数卡。

## Emotional arc
- 好奇（开场：分量乘积和几何投影，两种完全不同的算法为什么答案一样？）
- 顿悟（Step 2，aha moment：具体算例 45°，代数 7.07 与几何 3.16 × 2.24 = 7.07 严丝合缝）
- 确信（Step 3：360°旋转，影子由正变 0 变负，双读数毫厘不差同步更新）
- 聚焦（Step 4：停在直角，影子塌为一点，揭示点积为 0 即正交的几何本质）
- 升华（Step 5：联系分类器超平面，直观理解“点积就是看样本在权重法向走多远”）。

## Step 1 — 定义两向量 [stage 0]
- Purpose：建立二维坐标系，引入固定向量 u = (3, 1) 和旋转向量 v（长 2.5），展示代数与几何两种视角。
- Visual：绘制网格与轴；画出蓝色向量 u = (3, 1)（模长 3.16）及虚线延伸；画出黄色向量 v（45°）。右侧展示带角色注释的双视角公式卡。
- Math attached：u = (3, 1), ‖u‖ = √10 ≈ 3.16, ‖v‖ = 2.5；公式 u′v = u₁v₁ + u₂v₂（也写作 u·v）与 u′v = ‖u‖‖v‖cosθ；角色注释分两行、各自居中在所属分项下：‘‖u‖：u 的长度’、‘‖v‖cosθ：v 在 u 方向上的影子’。
- short：两视角：代数乘积 u₁v₁ + u₂v₂ 还是几何投影？
- Technical notes：使用 M() 渲染公式，角色注释用 T() 挂在各分项正下方。

## Step 2 — 投影与点积 [stage 1] (Aha moment)
- Purpose：在 45° 具体位置下，展示垂直虚线投影、绿色影子线段，验证代数与几何读数完全一致。
- Visual：从 v 的端点向 u 所在直线作灰色垂线；在 u 的直线上显示粗绿色影子线段；右侧双读数高亮呈现 7.07。
- Math attached：v ≈ (1.77, 1.77)；代数：3×1.77 + 1×1.77 = 7.07；几何：3.16 × 2.24 = 7.07。读数卡比公式卡低 8 px，给两行角色注释留空。
- short：v 投影到 u 上得到影子：3.16 × 2.24 ≈ 7.07
- Technical notes：用 always_redraw 绑定投影垂线、影子线段和两个读数面板。移动标签“影子 s”（14 号、带底框）放在 u 所在直线背离 v 的一侧，从影子中点沿影子向外滑到不压任何刻度数字/轴名/u 标签与箭头尖的位置；浅影子贴近 x 轴刻度行时改放 v 一侧、越过垂足处；都放不下（或 |s|<0.4）就暂时隐藏。45° 时标签挂在影子外段下方、x 轴刻度行之上。

## Step 3 — 360°旋转 [stage 2]
- Purpose：让 v 绕原点平滑旋转 360°，展示锐角（同向绿色 > 0）、钝角（反向红色 < 0）及正负变化。
- Visual：ValueTracker 驱动 v 匀速旋转一圈；垂线和影子动态追踪，同向绿、反向红；双读数同步翻滚。
- Math attached：实时更新 3×v₁ + 1×v₂ 与 3.16 × shadow；状态胶囊：锐角 > 0 / 钝角 < 0。
- short：360°旋转：锐角影子同向为正，钝角反向为负
- Technical notes：Line 零长度防崩处理（极小时转为 Dot）。影子标签按同一避让规则换边（v 越过 u 的直线时翻到另一侧），全程不遮刻度“1/2/3”与原点“O”。

## Step 4 — 正交：积为 0 [stage 3]
- Purpose：停在垂直位置，揭示 u′v = 0 ⇔ 向量垂直（正交）。
- Visual：v 停在 α ≈ 108.43°；垂线落入原点，影子缩为 0；原点出现直角弯角符号；读数显示 0.00；高亮正交卡片。
- Math attached：3×(-0.79) + 1×2.37 = 0.00；3.16 × 0.00 = 0.00；u′v = 0 ⇔ u ⊥ v（正交 orthogonal）。
- short：垂直时影子为 0：u′v = 0 ⇔ 正交（orthogonal）
- Technical notes：Circumscribe 强调正交充要条件。

## Step 5 — 连接分类器 [stage 4]
- Purpose：将 u 视为权重向量 w，解释等值线 w′x = c 与超平面分类器本质。
- Visual：u 标注转换为法向量 w（“法向量 (normal)” 完整可见）；画出三条垂直于 w 的等值线：w′x = 6、分界线 w′x - 3 = 0、w′x = 0。等值线标签在线的上端，黄色“边界”胶囊挂在黄线**下端**（不再盖住 w′x = 6）；x<sub>A</sub> 在点右侧、x<sub>B</sub> 在点左下（避开刻度 2 和青线）；“投影点完全相同！”右移避开青线。
- Math attached：ŷ = sgn(w′x + b)（法向 w）；“线性分类器就是在问 x 在 w 方向上走了多远”。右侧卡片最后一条分两行：“• 沿法向量 w 的方向越过分界线 ⇒ 正类；”/“反方向 ⇒ 负类”（续行与上一行文字左对齐，不压到卡片外）。
- short：分类器 w′x + b = 0：本质是看 x 在 w 方向走多远
- Technical notes：右侧角色卡左缘移到 x = 372 px（标题/公式中心 468 px），不遮挡 w 的标签；刻度数字 15 px #9aa3b2。

## Colours
- 蓝 = 向量 u (3, 1) 及分类器权重向量 w
- 黄 = 旋转向量 v、决策边界 w′x + b = 0
- 绿 = 同向投影（影子）、点积正值、几何等值线
- 红 = 反向投影（负影子）、点积负值
- 灰 = 坐标网格、坐标轴、垂线与角色注释

## Takeaway
- 点积是投影长乘模长：代数与几何完全统一
- 正交充要条件：u′v = 0 ⇔ 两向量垂直
- 线性分类器：w′x + b 是看 x 在法向 w 走了多远
