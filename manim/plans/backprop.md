# backprop · 反向传播（c34）

## Overview
- **Hook**：每个权重都要知道“改它一点点，损失变多少”——逐个求导太慢，能不能一次全算完？
- **Key insight（aha，第 4 步 + 第 6 步）**：每条边的梯度 = 终点的误差 × 起点的值；误差 δ、ε 每个只算一次就被复用。
- **Narrative pattern**：Build up → Payoff（先前向记下每个值，再让误差往回流，最后所有梯度一次到手）。
- **FLOW**：前向算值 → 损失 → 输出误差 δ → 输出层梯度 → 隐藏误差 ε → 输入层梯度
- **Emotional arc**：好奇 → 困惑（这么多权重）→ 部分明白（δ 只算一次）→ aha（规则卡“误差 × 值”）→ 满足（同一规则在输入层再用一次）。

## Steps（skeleton = 2-2-1 网络，全程不清空；蓝点 = 前向，红点 = 反向）
1. 前向①：蓝点沿输入边流动；标 r₁ = 1.5 → u₁、r₂ = 0.5 → u₂。
2. 前向②：流到 z；标 z = 1，L = 0.5。
3. 输出误差：z 变红圈，δ = z − y = 1。
4. 输出层梯度（aha）：红点逆流；三条边贴红色药丸 1、1.5、0.5；右上出现规则卡“梯度 = δ × u”，两项各标作用。
5. 隐藏误差：u₁、u₂ 变红，ε₁ = 1、ε₂ = −1（δ·w·g′）。
6. 输入层梯度：四条边贴 ±1；规则卡就地变成“梯度 = ε × x”——同一条规则。

## Colours
蓝 = 往前流的值；红 = 往回流的误差 / 梯度；黄 = 数值标签。

## Takeaway
前向：数值从左往右流 / 反向：误差 δ、ε 从右往左流（每个只算一次）/ 每条边的梯度 = 终点的误差 × 起点的值
