# Bias–Variance Trade-off (c19) 故事板

## Overview
- **Hook**: 为什么模型不是越复杂越好？换一份数据，学到的模型到底会怎么变？
- **Key Insight (Aha moment)**: 直线每次都稳定地偏低（低方差、高偏差）；7 次多项式每次都在真值两侧大幅晃，但平均下来几乎正中真值（高方差、低偏差）。3 天的画面由 4000 天模拟背书，两者此消彼长，总误差呈 U 形。
- **Narrative Pattern**: 左右对照（Simple vs Complex）+ 换数据思想实验（周一 / 周二 / 周三）+ 局部放大（测试点 $x_0=0.6$ 的预测搬到同刻度数轴上）+ 长期模拟背书 + 理论收拢（公式与 U 形曲线）。
- **FLOW**: `['真实与采样', '换数据拟合', '测试点表现', '偏差与方差', '误差分解']`
- **Aha Step**: Step 6–7（多项式三天散开 0.58，但黄色平均刻度贴着白色真值；4000 天灰点云证实这不是巧合）。

## 数据与诚实性
- $f(x)=\sin(2.5x)$，10 个点 `linspace(-0.95, 0.95, 10)`，噪声 $\sigma = 0.25$；三天数据 `default_rng(7532)` 依次抽 3×10 个噪声。
- 种子由程序搜索得到，条件：三天要像长期平均——直线三天都明显低于真值、彼此接近；多项式三天跨在真值两侧、极差 > 0.4、均值距真值 < 0.08；多项式曲线在整个面板（两端、弯折处）都明显分开。
- 画面与字幕的所有数字都由场景内 f-string 从拟合结果计算；场景开头有 `assert` 守住字幕里的每条结论（换种子若不成立会直接报错）。
- 4000 天模拟（`default_rng(0)`）：直线 bias −0.30、sd 0.11；7 次 bias 0.00、sd 0.22；期望误差（含 $\sigma^2$）1 次 0.17 / 3 次 0.08 / 7 次 0.11 / 9 次 0.23。

## Steps
1. **真实与采样** (stage 0)
   - *Visual*: 左右两面板画出真实曲线 $f(x)=\sin(2.5x)$（细白线，标签“真实 f(x)”贴在波谷下方）+ 周一数据（蓝色 10 点）。
   - *Math*: $y = f(x) + \epsilon$，$\epsilon \sim \mathcal{N}(0, 0.25^2)$。
   - *Short*: `真实函数 f(x)=sin(2.5x)，周一采样 10 个含噪数据点`
2. **换数据拟合（周一）** (stage 1)
   - *Visual*: 左边拟合直线（蓝），右边拟合 7 次多项式（蓝，超出 $[-2,2]$ 处截断分段）。
   - *Math*: 拟合残差均方根：直线 0.39，多项式 0.05（8 个参数 = $x^0$ 到 $x^7$ 各一个系数；10 个点，几乎贴着每个点，但不是全部穿过）。
   - *Short*: `用周一数据拟合：直线欠拟合，多项式几乎贴着每个点`
3. **换数据拟合（周二、周三）** (stage 1)
   - *Visual*: 加入周二（绿）和周三（紫）的数据与拟合。三条直线几乎叠在一起；三条多项式在两端和弯折处明显分开。
   - *Short*: `换周二、周三的数据：三条直线几乎重合，三条多项式明显分开`
4. **测试点表现** (stage 2)
   - *Visual*: 两面板画竖直虚线 $x_0=0.6$、白色真值刻度、三天交点彩点；面板下方各出现一条**同刻度放大数轴**（0.4–1.6，白色刻度“真值 0.997”），彩点从面板飞到数轴上（TransformFromCopy）。
   - *Short*: `固定测试点 x₀=0.6，把三天的预测搬到下方数轴上`
5. **偏差与方差（直线）** (stage 3)
   - *Visual*: 聚光左面板。数轴上：黄色平均刻度“平均 0.71”，平均与真值之间的黄色色带 = 偏差。下方三行：`周一 0.63 周二 0.78 周三 0.73` / `平均偏 −0.28 → 高 Bias` / `3 天相差最多 0.15 → 低 Variance`。
   - *Short*: `直线：三天挤在一起，但平均偏 −0.28 ⇒ 低方差、高偏差`
6. **偏差与方差（多项式）** (stage 3)
   - *Visual*: 聚光右面板。三天 1.31 / 0.74 / 1.00 跨在真值两侧，黄色平均刻度 1.02 贴着白色真值刻度。三行：`平均偏 +0.02 → 低 Bias` / `3 天相差最多 0.58 → 高 Variance`（直线的 3.9 倍）。
   - *Short*: `多项式：三天散开 0.58（高方差），平均只偏 +0.02（低偏差）`
7. **长期模拟背书** (stage 3)
   - *Visual*: 两条数轴上淡入灰色点云（4000 天中 300 天的预测）：左边紧凑、整体在真值左侧；右边宽、以真值为中心。底部框：`模拟 4000 天：直线 偏 −0.30、晃 ±0.11；多项式 偏 0.00、晃 ±0.22`。
   - *Short*: `不是巧合：换 4000 份数据，直线总是偏低，多项式总在真值两侧晃`
8. **误差分解** (stage 4)
   - *Visual*: 面板淡出；公式 + 每项作用注释；示意 U 形曲线（bias² 黄、variance 绿、Var[Y] 灰虚线、总误差红、最佳平衡点；横轴“模型复杂度（多项式次数）”，c19 不用“自由度”一词）；下方一行本例数字：`1 次 0.17 · 3 次 0.08（最低）· 7 次 0.11 · 9 次 0.23`。
   - *Math*: $\mathrm{E}[(Y-\hat f)^2] = \text{bias}^2 + \text{variance} + \mathrm{Var}[Y]$（按 c19 的写法；噪声项注释为“数据噪声 σ²，谁也消不掉”，本例 $\mathrm{Var}[Y]=\sigma^2=0.25^2$）。
   - *Narration（新手补丁）*: 先认符号——$\hat f$ = 模型在 $x_0$ 的预测；$Y$ = 真值 $f(x_0)$ + 一次新的随机噪声，方差 $\sigma^2=0.25^2=0.0625$（本章写 $\mathrm{Var}[Y]$）；$\mathrm E[\cdot]$ = 对无数份训练数据（和测试噪声）取平均，网页第 8 步的 4000 次模拟近似其中对训练数据的部分；拆分的推导指向正文“数学定义”一节的“推导”（$\mathrm E[Z^2]=\mathrm{Var}[Z]+(\mathrm EZ)^2$）。
   - *Short*: `期望测试误差 = bias² + variance + 噪声，总误差通常呈 U 形`

## Colours
- **WHITE**: 真实目标 $f(x)$，真值刻度 $f(0.6)$
- **BLUE / GREEN / PURPLE**: 周一 / 周二 / 周三 的数据、拟合与预测点
- **YELLOW**: 平均预测刻度、偏差色带、bias 读数、$\text{bias}^2$
- **GREEN**: variance 读数、$\text{variance}$
- **GREY**: 坐标轴、4000 天模拟点云、不可约噪声 $\mathrm{Var}[Y]$（$=\sigma^2$）
- **RED**: 总测试误差 U 形曲线

## Takeaway
- 一句话：简单模型高偏低方，复杂模型低偏高方
- 核心公式：测试误差 = bias² + variance + 噪声
- 考点与决策：调正则 / 选模型：寻找 U 形谷底最佳平衡
