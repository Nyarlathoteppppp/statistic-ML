# msgpass · 树上的消息传递（c56）

## Overview
- **Hook**：想知道 x₄ 热的概率，要把其余房间的所有组合加起来——能不能每条边只算一次？
- **Key insight（aha，第 5 步）**：消息 = 把一棵子树提前加掉后剩下的（热，冷）两个数；中间点只需“乘来信、加掉自己”。
- **Narrative pattern**：Wrong → Right（先暴力枚举 16 种组合，再换成从叶子往里推的求和）。
- **FLOW**：笨办法：枚举 → 叶子：加掉自己 → 消息 → 中间点：乘来信再加掉 → 根：相乘、归一化
- **Emotional arc**：好奇 → 困惑（16 个方块，房间多了就爆炸）→ 部分明白（叶子把自己加掉）→ aha（x₂ 合并来信）→ 满足（结果和暴力一样）。

## Steps（skeleton = 5 个房间的树，全程不清空）
1. 笨办法：16 个蓝方块逐个出现（固定 x₄ 后的组合数 2⁴）。
2. 叶子 x₅：右侧面板写 3 + 1 = 4、1 + 2 = 3，黄色消息 (4,3) 沿边飞向 x₄。
3–4. 叶子 x₁、x₃：消息 (4,2)、(3,2) 飞向 x₂。
5. x₂（aha）：两条来信合并成 (12,4)，再乘 ψ₂₄ 加掉 x₂ → (52,20) 飞向 x₄。
6. x₄：(52,20) 与 (4,3) 相乘 → 红色 (208,60)，柱状图 0.78 / 0.22。

## Colours
黄色药丸 = 消息；棕色填充 = 已被加掉的房间；红圈 = 查询目标 x₄；红 / 蓝柱 = 热 / 冷。

## Takeaway
消息 = 把一棵子树提前加掉后剩下的（热，冷）两个数 / 每条边只传一次：先乘来信，再把自己加掉 / 结果与暴力枚举完全相同，计算量随房间数线性增长
