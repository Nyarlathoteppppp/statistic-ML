# msgpass · 树上的消息传递（c56）

## Overview
- **Hook**：想知道 x₄ 热的概率，要把其余房间的所有组合加起来——能不能每条边只算一次？
- **Key insight（aha，第 3 步起）**：每张 ψ 表一律按（行 = 发送者，列 = 收件人）排，把发送者加掉就永远是“每一列上下相加”；两个列和装进消息，消息里的两个数永远是（收件人热时，收件人冷时）。
- **Narrative pattern**：Wrong → Right（先暴力枚举 16 + 16 种组合，再换成从叶子往里推的求和）。
- **FLOW**：笨办法：枚举 → 叶子：每列相加成消息 → 中间点：乘来信、乘 ψ、求和 → 根：相乘、归一化
- **Emotional arc**：好奇 → 困惑（16 个红方块 + 还要再算 16 个）→ 部分明白（叶子的表每列相加）→ aha（x₂：来信逐项相乘当行权重，再每列相加）→ 满足（208/268 与暴力枚举相同）。

## 记号与数据（与 c56 表格一致）
ψ 表列为 热·热、热·冷、冷·热、冷·冷，对应 ψ_ij(x_i, x_j)：ψ₁₂ = 3,1,1,1；ψ₂₃ = 1,2,1,1；ψ₂₄ = 4,1,1,2；ψ₄₅ = 3,1,1,2。
屏幕上的 2×2 表（行 = 发送者 热/冷，列 = 收件人 热/冷）：

| 消息 | 表 | 是否转置 | 热列 | 冷列 |
|---|---|---|---|---|
| m₅→₄ | 行 x₅、列 x₄：[[3,1],[1,2]] | ψ₄₅(x₄,x₅) 转置（恰好对称） | 3+1=4 | 1+2=3 |
| m₁→₂ | 行 x₁、列 x₂：[[3,1],[1,1]] | 原顺序 | 3+1=4 | 1+1=2 |
| m₃→₂ | 行 x₃、列 x₂：[[1,1],[2,1]] | ψ₂₃(x₂,x₃) 转置（2 换位置） | 1+2=3 | 1+1=2 |
| m₂→₄ | 行 x₂、列 x₄：[[4,1],[1,2]]，行权重 (12,4) | 原顺序 | 4×12+1×4=52 | 1×12+2×4=20 |

x₄：(52×4, 20×3) = (208, 60)；÷268 ⇒ 0.78 / 0.22。

## Steps（skeleton = 5 个房间的树，全程不清空；右侧是工作面板，每步换一次）
0. 问题卡。
1. 笨办法（≈11 s）：树淡入，x₄ 红圈旁标“要问的”。面板：“x₄=热：16 种组合” + 16 个红方块；第 1 个方块放大成一个框：x₁ x₂ x₃ x₅ 全热，3 × 1 × 4 × 3 = 36（每个因子下标 ψ₁₂…ψ₄₅，树上各房间旁出现红色“热”、四条边的 ψ 依次闪亮）；再出现“x₄=冷：还要再算 16 种” + 16 个蓝框。
2. 叶子 x₅（≈11.5 s）：边 ψ₄₅ 变黄、x₅ 闪一下。标题 m₅→₄：把发送者 x₅ 加掉；小字“ψ₄₅ 按（发送者 x₅，收件人 x₄）排：ψ₄₅(x₄,x₅) 行列对调”。表先按给定顺序出现（行 x₄、列 x₅），再转置：旧行列标签先淡出、新标签再淡入（交叉淡变，不让两套标签互相变形），同时非对角两个数沿弧线互换。规则行“把发送者 x₅ 加掉 = 每一列上下相加”。黄框框住 x₄热 列，两格数字落下成 3+1=4；黄框移到 x₄冷 列，1+2=3。两个和飞进 x₅ 处的黄色药丸“x₄热 4，x₄冷 3”，药丸沿边停到 x₄–x₅ 下方；x₅ 变灰并标“已加掉”。右下角此时才出现说明：消息里的两个数 =（收件人热时，收件人冷时）。
3. 叶子 x₁（≈8.5 s）：同样流程，ψ₁₂ 原顺序（不转置），3+1=4、1+1=2 → “x₂热 4，x₂冷 2”。
4. 叶子 x₃（≈11.6 s）：ψ₂₃ 先按 ψ₂₃(x₂,x₃) 出现，红框框住右上角的 2（= ψ₂₃(热,冷)），转置前停约 1.3 s；转置时标签交叉淡变，2 沿弧线从（x₂热，x₃冷）换到（x₃冷，x₂热），红框跟着 2 一起走，之后一直留在那一格（属于面板，面板清空时才淡出），黄框框到 x₂热 列时红框仍在框内；1+2=3、1+1=2 → “x₂热 3，x₂冷 2”。
5. x₂（aha，≈12.6 s）：两条来信复制到面板并排放（中间 ×），树上原药丸变灰。红框圈两封信的“热”数字 → x₂热：4×3=12；蓝框圈“冷”数字 → x₂冷：2×2=4。ψ₂₄ 表（行 x₂、列 x₄，原顺序）出现，12、4 飞到右侧成为行权重 ×12、×4（列头“来信乘积”）。热列：格子变成 4×12、1×4，落下成 48+4=52，停约 0.85 s；冷列：1×12、2×4 → 12+8=20，再停。52、20 飞进 x₂ 正下方（x₂–x₄ 边右侧、避开已停放的 m₃→₂）的药丸“x₄热 52，x₄冷 20”，药丸沿 x₂–x₄ 边竖直往下滑，停在 x₄ 右上方，全程不经过 x₃ 一侧；x₂ 变灰“已加掉”。
6. x₄（≈11.2 s）：两封来信并排逐项相乘：52×4=208，20×3=60。先画未归一化的柱子（208、60，数字从乘积飞过去；柱高压到 98 px，使 0.78 标签和它的黄框不碰到上方小标题），再出现“两个都除以 208 + 60 = 268”；旧柱顶数字和小标题先淡出，再淡入 208/268 ≈ 0.78、60/268 ≈ 0.22 和“概率 P(x₄)”（不做变形，避免标签糊在柱顶），最后圈出 0.78。
7. 总结卡。

## Colours
黄色药丸 = 消息（文字写明收件人的热 / 冷值，不用“·”分隔）；用过的消息变灰；灰色填充 + “已加掉” = 已被加掉的房间（不用暖棕色，避免读成“热”）；红圈 + “要问的” = 查询目标 x₄；红框 = 转置后真正换了位置的那一格（x₃ 步）；表头紫色 = 发送者（行），青色 = 收件人（列）；黄框 = 正在相加的那一列；红 / 蓝 = 热 / 冷（方块、乘法框、柱子）。

## Takeaway
消息 = 发送者那一侧加掉后剩下的（收件人热，收件人冷） / 其他来信相乘 → 乘通往收件人的 ψ → 对发送者求和 / 求一个节点的边缘时，每条边朝它传一次 / 到达后来信相乘、归一化 = 暴力枚举的结果

总时长约 77 s。
