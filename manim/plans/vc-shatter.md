# Storyboard: VC 维 —— 从“打散”到查表（c23，T1 题型）

## Overview
- **Hook (question card)**：`一个模型类有多灵活？` / `数一数：它最多能把几个点“任意贴标签”`
- **Key insight（aha，第 5 步）**：表里的一行 = 一个分类器在这几个点上贴出的标签，一列 = 一个点；“打散”翻译成表的语言就是“只看这几列，2ᵏ 种 0/1 组合全出现”。几何直觉和考试的机械查表是同一件事。
- **Narrative pattern**：先看懂（直线在平面上贴标签）→ 看到极限（共线、4 点为什么做不出）→ 翻译成表 → 用表做两道真题（L07 p29、2026 practice Q3 陷阱）。
- **FLOW**：`['什么叫打散', '三点 8/8', '共线：存在就行', '四点总缺一种', '图 → 表', '查表求 VC', '行数够≠打散']`
- **Notation（与 c23 一致）**：点 x₁…xₙ；标签 + / −，表里写 1 / 0（1 红、0 蓝，与 + 红、− 蓝同色）；VC(F) = 能被打散的最大点集大小；上界 ⌊log₂(不同行数)⌋。
- **Persistent conventions**：直线一侧浅红 = 判 +；红点带“+”、蓝点带“−”。第 2 步点色跟着直线变；从第 4 步起点色是“想要做出的标签”（旁白明说），黄圈 = 这条线贴错的点，第 5 步的黄点是对角线交点（旁白区分）。集齐卡：灰字格 = 还没出现的组合，变绿 = 已出现，红字“重复” = 去重。每步开始时清掉上一步的画面（`clear_stage()`），所以 ⏭ 暂停时停在完整画面上。

## Emotional arc
好奇（怎么量“灵活”）→ 看懂（直线一动，标签就变）→ 满足（8/8）→ 警惕（共线做不出，但“存在”就够）→ 恍然大悟（对角线交点：哪边都不是）→ 连上考试（图 → 表）→ 熟练（集齐 8 格）→ 防坑（8 行却只有 VC 2）。

## Steps
1. **问题卡**：为什么要数点；shatter 和 VC 维的一句话定义。
2. **什么叫打散**（stage 0）：三角形 3 点 + 一条会动的直线（ValueTracker 控制角度和偏移，`always_redraw` 让点的颜色和读数“这条线贴出：x₁± x₂± x₃±”实时更新）；依次做出 + − −、− − +、− + +、+ + −。右侧卡片：dichotomy（二分）、2³ = 8、shatter 的定义。
3. **三点 8/8**（stage 1）：2×4 小格，每格一种标签（符号写在格子上方），各配一条做得到的直线（360 个方向里间隔最宽的那条；全同号时放在点外），计数 1/8 … 8/8 ⇒ VC ≥ 3。
4. **共线：存在就行**（stage 2）：共线 3 点要做 + − +；试 3 条线，每次黄圈标出贴错的点；红色粗线 = 两个 + 点之间的整段都在 + 侧（旁白给理由：线段与直线最多交一次；式子 w'x+b 沿线段均匀变化），x₂ 在上面只能是 +。卡片：这组没被打散，但 VC 维只要求“存在”一组。
5. **四点总缺一种**（stage 3）：正方形 XOR 标签，直线（偏离中心 0.95 单位）转一整圈，读数“贴错 k 个”在 1、2、3 之间变化，从不为 0；红、蓝对角线交于黄点 ⇒ 矛盾。右边：外三 + 内一 −，+ 三角形整块在 + 侧。旁白：4 点摆法只有三类（四边形 / 一点在三角形里 / 三点共线），每类缺一种，对调 ± 再缺一种 ⇒ 至少缺 2 种，16 种最多 14 种；存在一组 3 点被打散、任何 4 点都不行 ⇒ 直线 VC = 3。
6. **图 → 表**（stage 4）：8 个小格的符号依次飞进右边表格，变成 000…111；注释 + 记 1、− 记 0、一行 = 一条线贴的标签、一列 = 一个点；打散 ⇔ 只看这几列，000 到 111 全出现。
7. **查表求 VC**（stage 5）：L07 p29 表（10 行 × 4 列）。① 10 < 16，⌊log₂10⌋ = 3；② 调暗 x₃ 列，逐行读 (x₁, x₂, x₄)，放进 8 格“集齐卡”，第 5 行 010、第 7 行 111 标“重复”；③ 8/8 ⇒ {x₁, x₂, x₄} 被打散 ⇒ VC = 3（{x₁, x₂, x₃}、{x₂, x₃, x₄} 也行）。
8. **行数够≠打散**（stage 6）：2026 practice Q3（8 行 × 5 列）。上界 3；试 (x₁, x₃, x₄)：7 种、缺 101（红框）；预筛：每列 0、1 各要 ≥ 4 个，只有 x₃、x₄ 合格 ⇒ 凑不出 3 列 ⇒ VC ≤ 2；退到 (x₁, x₂)：4/4 ⇒ VC ≥ 2 ⇒ VC = 2。
9. **总结卡**：VC 维定义；打散 = 2ⁿ 种全做得出、存在一组即可；查表三步；ℝ² 直线 VC = 3，ℝᵈ 线性分类器 VC = d + 1。

## Checks（`check_numbers()` 在渲染时断言）
- 三角形 8/8 可分；共线 + − + 不可分、共 6 种；正方形 XOR、外三内一的“内点异号”不可分；两种 4 点摆法都恰好 14 种。
- L07：(x₁, x₂, x₄) 去重后 8 种，重复行是第 5、7 行；被打散的三元组恰为 {1,2,3}、{1,2,4}、{2,3,4}。
- Q26：10 种三元组都不足 8 种；(x₁, x₃, x₄) 7 种、只缺 101；(x₁, x₂) 4 种；0、1 各 ≥ 4 个的列只有 x₃、x₄。
