# conv · 1D 卷积与参数计数（c38）

## Overview
- **Hook**：图像拉平成向量喂给全连接网络，既丢了空间结构、参数又爆炸。怎样用极少的参数看懂整张图？
- **Key insight（aha，第 4 步）**：权重共享——同一个小检测器（3 个权重）滑过所有位置，参数量由 filter 大小决定，与输入和输出的尺寸完全无关！
- **Narrative pattern**：Operational → Structural + Contrast（先具体算滑动点积与差分直觉，再抽象为连线图揭示权重共享，最后对比全连接的 15 条线）。
- **FLOW**：设定与对准 → 逐位相乘求和 → 滑动算完全程 → 权重共享 → 对比全连接
- **Emotional arc**：好奇（提问）→ 踏实（一步步算清乘积与求和）→ 恍然大悟（为什么输出全是 −2，模板在问什么）→ aha（连线图里只有 3 种颜色，权重共享）→ 满足（对比全连接 15 条独立线，T3 真题考点彻底攻克）。

## Steps（skeleton = 5 个输入单元 + 3 个输出单元，全程保留）
1. **设定与对准**（stage 0）
   - Purpose：明确全部设定（单通道、单 filter、无偏置、stride 1、无 padding、CNN 互相关不翻转）并对准首个窗口。
   - Visual：上方 5 个蓝色输入单元 [1, 2, 3, 4, 5]，下方 3 个暗框输出单元；宽 3 的 filter [1, 0, −1]（青、紫、橙）携高亮选框对准前 3 格。
   - Math：输入 a = [1, 2, 3, 4, 5]，权重 w = [1, 0, −1]，宽 k = 3，步长 s = 1。
   - Narration：channel = 每个位置叠了几层数（RGB = 3 个输入通道；这里每格一个数 → C_in = 1；几个 filter 就几层输出 → C_out = 1）；数学课本的卷积要先左右翻转模板，深度学习不翻（cross-correlation）。
   - short：`单通道、单 filter、无偏置：宽 3 模板对准输入前三格`
2. **逐位相乘求和**（stage 1）
   - Purpose：展示卷积的基本算子——逐格相乘再相加。
   - Visual：输入与 filter 之间浮现三个乘积 1×1=1、2×0=0、3×(−1)=−3；下方聚合为求和式 1 + 0 + (−3) = −2；随后求和式下落填入第 1 个输出格，高亮闪烁。
   - Math：1·1 + 2·0 + 3·(−1) = −2。
   - short：`逐格相乘再求和：1×1 + 2×0 + 3×(−1) = −2`
3. **滑动算完全程**（stage 2）
   - Purpose：完成滑动，得出全部输出，并揭示检测器的几何/物理直觉。
   - Visual：模板右移到 [2, 3, 4]，算得 2 − 4 = −2 填入第 2 格；再右移到 [3, 4, 5]，算得 3 − 5 = −2 填入第 3 格。输出格填满 [−2, −2, −2]。弹出直觉释义卡：[1, 0, −1] 衡量“左邻 − 右邻”差分。
   - Math：(5 − 3)/1 + 1 = 3 个输出；输出均为 −2（输入每步递增 1）。
   - Narration：⌊(5−3)/1⌋+1 的来由——模板最左端从第 1 格出发每次挪 s 格，最多挪 2 次，加出发那格共 3 个位置；⌊ ⌋ = 向下取整，零头不算。直觉卡前先写 1×左 + 0×中 + (−1)×右 = 左 − 右。
   - short：`模板右移：输入处处递增 1，“左−右”差分处处为 −2`
4. **权重共享（aha）**（stage 3）
   - Purpose：转换为网络图视角，揭示参数量为 3（权重共享）的核心机理。
   - Visual：滑窗淡出，展开输入到输出的 9 条连线；按权重分为 3 种颜色（青、紫、橙）；右侧给出权重图例与参数卡片。
   - Math：参数量 = 3（与输出位置数 3 无关；含 1 个共享 bias 则为 4）。
   - short：`权重共享：同色边共用同一参数，本层仅 3 个权重`
5. **对比全连接**（stage 4）
   - Purpose：对比全连接网络（5×3=15 条独立连线），击破考试陷阱。
   - Visual：卷积连线淡入淡化，叠加上 5×3 = 15 条灰色全连接线；弹出对比徽章与真题提醒。
   - Math：全连接 5×3 = 15 个独立权重 vs 卷积 3 个共享权重。
   - short：`对比全连接：5×3 = 15 条独立连线 vs 卷积仅 3 个参数`

## Colours
- 蓝（BLUE）：输入单元外框
- 青（TEAL）：filter 权重 w₁ = 1 及对应连接
- 紫（PURPLE）：filter 权重 w₂ = 0 及对应连接
- 橙（ORANGE）：filter 权重 w₃ = −1 及对应连接
- 黄（YELLOW）：计算求和、输出高亮、核心强调
- 灰/暗（DIM / GREY）：未激活单元框、全连接对比连线、说明文字

## Takeaway
（旁白补：补零 = 输入两头各添 p 个 0，让模板盖到边上的格子，输入长度变成 n + 2p；本例 p = 0。）
- 卷积 = 小模板滑过输入做点积：同一检测器在所有位置复用
- 输出尺寸 ⌊(n + 2p − k)/s⌋ + 1 = 3（与 stride、padding 有关）
- 参数只有 3 个（权重共享）：绝不随输出位置重复计数！
