# perceptron · 感知机更新与几何直觉（c31）

## Overview
- **Hook / Question**（问题卡第 2 行也是问句：随手猜一条线，分错了该怎么改？）：两类数据，如何用直线分开？如果不知道最佳分界线在哪，能不能从一条随意猜的线开始，**每分错一个点，就把线往那个点推一下**？
- **Key insight（aha，第 3 步）**：分界线不是凭空算出来的，而是被每个分错的点“硬生生推过去”的；正类点把线往外推，负类点把线往里推；一旦分对，线就一动不动。
- **Narrative pattern**：Predict & Push（几何修正循环）。以具体数值例子逐点手算，直观展示权重向量旋转与分界线扫动。
- **FLOW**：规则与初始线 → 样本1：推向负类 → 样本2：推向正类 → 样本3：分对不动 → 第2轮与收敛
- **Notation（与 c31 / L10 p33–p39 一致）**：得分 s = w₁x₁ + w₂x₂ + w₀ = w'x；权重一律按 (w₁, w₂, w₀) 排，样本 x = (x₁, x₂, 1)（bias 输入放最后）；更新条件 y·s ≤ 0，规则 w ← w + η·y·x。不用 ŷ、不用 y − ŷ。
- **Persistent skeleton**：左侧 2D 坐标系（[-0.5, 3] × [-0.5, 2.5]）、数据点（(1,1)、(2,1)、(1.5,0.5)，标签只写坐标，类别看颜色/形状 + 右下图例）、分界线、权重向量法向箭头（起点在分界线 25% 处，若离数据点或坐标标签太近则沿线另选位置）和正半平面着色全程保留；右侧信息卡展示当前权重 (w₁, w₂, w₀) 与算术步骤（MathTex 24–27 号）。

## Step 1 — 规则与初始线 [stage 0]
- Purpose：建立二维几何平面，展示初始分界线与权重向量，给出带角色注释的更新规则。
- Visual：绘制坐标系与 3 个样本点；初始权重 (w₁, w₂, w₀) = (0.2, 0, -0.1) 生成初始竖直线 x₁ = 0.5；绿色分界线、法向箭头 w 指向右侧（+1 半平面）。右侧展示角色注释更新公式。
- Math attached：s = w₁x₁ + w₂x₂ + w₀ = w'x；公式 w ← w + η y x，标注 η ‘步长 0.1’、y ‘真实标签 ±1：往哪边推’、x = (x₁, x₂, 1) ‘沿这个样本推’；y·s ≤ 0 分错 ⇒ 更新，y·s > 0 分对 ⇒ 不动。
- short：初始线 x₁ = 0.5：得分 s = w₁x₁ + w₂x₂ + w₀
- Technical notes：使用 M() 呈现公式，中文注释用 T() 挂在各分项正下方。

## Step 2 — 样本 1：推向负类 [stage 1]
- Purpose：处理样本 (1, 1)，真实 y = -1，展示分错时的负向更新与分界线旋转。
- Visual：黄圈高亮点 (1, 1)；右侧展示计算；分界线顺时针转动到 x₂ = x₁ − 2，法向箭头 (w₁, w₂) 旋转到 (0.1, -0.1)，将点 (1, 1) 推出红色正类区域。
- Math attached：s = 0.2×1 + 0×1 + (-0.1) = 0.1；y·s = −0.1 ≤ 0 ⇒ 分错；(w₁, w₂, w₀) ← (0.2, 0, -0.1) − 0.1×(1, 1, 1) = (0.1, -0.1, -0.2)。
- short：点 (1,1) 标签 −1 却判 +1：分界线推向该点
- Technical notes：负数运算严格使用括号；ReplacementTransform 平滑过渡分界线、箭头和权重读数。

## Step 3 — 样本 2：推向正类 [stage 2] (Aha moment)
- Purpose：处理样本 (2, 1)，真实 y = +1，展示正向更新如何将正类点纳入正半平面。
- Visual：高亮点 (2, 1)；计算显示 s = -0.1 < 0（被分到负侧）；分界线逆时针转动至 x₁ = 1/3，法向箭头指向正右方，把 (2, 1) 重新纳入正侧。
- Math attached：s = 0.1×2 + (-0.1)×1 + (-0.2) = -0.1；y·s = −0.1 ≤ 0 ⇒ 分错；(w₁, w₂, w₀) ← (0.1, -0.1, -0.2) + 0.1×(2, 1, 1) = (0.3, 0, -0.1)。
- short：点 (2,1) 标签 +1 却判 −1：分界线推向正侧
- Technical notes：两步连看，直观感受“分错就朝它推”的物理推力。

## Step 4 — 样本 3：分对不动 [stage 3]
- Purpose：对照展示：分对（y·s > 0）不满足更新条件，线与权重保持静止。
- Visual：高亮点 (1.5, 0.5)；点上闪烁绿色勾号；分界线和箭头一动不动；指出虽然此点分对，但第 1 个点 (1, 1) 又落入错侧。
- Math attached：s = 0.3×1.5 + 0×0.5 + (-0.1) = 0.35；y·s = 0.35 > 0 ⇒ 分对，不更新 ⇒ (w₁, w₂, w₀) 保持 (0.3, 0, -0.1)。
- short：点 (1.5,0.5)：y·s = 0.35 > 0 分对，分界线不动
- Technical notes：用静止强化“分对不动”的核心规则，并引出需要第 2 轮。

## Step 5 — 第 2 轮与收敛 [stage 4]
- Purpose：再跑一轮修正 (1, 1)，验证全部分对，解释收敛定理与解的非唯一性。旁白先说明课件只算到第 3 个点，这一轮是延伸。
- Visual：复查 (1, 1)，分错，分界线转动到 2x₁ − x₂ = 2；快速展示三点全部正确；绿牌“全部正确 · 收敛停机”。
- Math attached：(1,1): s = 0.2，y·s = −0.2 ≤ 0 ⇒ (w₁, w₂, w₀) ← (0.3, 0, -0.1) − 0.1×(1, 1, 1) = (0.2, -0.1, -0.2)；三点检验：s = -0.1, 0.1, 0.05，符号全对。
- short：第 2 轮修正 (1,1)：三点全分对，收敛停机
- Technical notes：对比 SVM 最大间隔，说明感知机只求“一条能分开的线”。

## Takeaway
- 分错推线，分对不动
- w ← w + η·y·x（只在 y·s ≤ 0 时）
- 线性可分必收敛，但不求最大间隔
